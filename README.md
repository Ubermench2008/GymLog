# GymLog
GymLog — офлайн-дневник силовых тренировок работающий на Android. 
Приложение помогает записывать упражнения, подходы, веса и повторения, а затем возвращаться к истории тренировок.

## Функциональность
### 1. История тренировок

Главный экран приложения.

Пользователь может:
- Просматривать список сохранённых тренировок.
- Видеть название и дату каждой тренировки.
- Создавать новую тренировку.
- Открывать ранее созданную тренировку.
- Удалять тренировку вместе с её упражнениями и подходами.

### 2. Управление тренировкой

Пользователь может:
- Задавать название и дату тренировки.
- Добавлять собственные или существующие упражнения.
- Указывать название каждого упражнения.
- Удалять упражнения из тренировки.
- Добавлять подходы к упражнениям.
- Указывать вес и количество повторений для каждого подхода.
- Редактировать и удалять подходы.

### 3. Локальное хранение

- Все тренировки, упражнения и подходы сохраняются в БД.
- Данные сохраняются между запусками приложения.
- Изменения в базе данных отражаются в пользовательском интерфейсе.

## Основные пользовательские сценарии

### Сценарий 1. Создание тренировки

1. Пользователь открывает приложение.
2. Нажимает кнопку создания тренировки.
3. Указывает название и дату.
4. Добавляет упражнение.
5. Добавляет несколько подходов с весом и повторениями.
6. Сохраняет результаты.
7. Новая тренировка появляется в истории.

### Сценарий 2. Просмотр истории

1. Пользователь открывает список тренировок.
2. Выбирает ранее сохранённую тренировку.
3. Просматривает упражнения и результаты подходов.

### Сценарий 3. Редактирование результатов

1. Пользователь открывает существующую тренировку.
2. Выбирает подход.
3. Изменяет вес или количество повторений.
4. Сохраняет изменения.
5. При повторном открытии отображаются обновлённые данные.

### Сценарий 4. Удаление тренировки

1. Пользователь выбирает тренировку.
2. Удаляет её.
3. Тренировка исчезает из истории.
4. Связанные упражнения и подходы также удаляются.

## Критерии готовности

Приложение считается готовым, если:

- Пользователь может создавать, просматривать и удалять тренировки.
- Пользователь может добавлять и удалять упражнения.
- Пользователь может создавать, редактировать и удалять подходы.
- Данные сохраняются после закрытия и повторного запуска приложения.
- Интерфейс корректно обновляется при изменении данных.
- Основные пользовательские сценарии выполняются без ошибок.

## Возможные расширения
- Экран прогресса по отдельным упражнениям.
- Графики изменения рабочих весов.
- Шаблоны тренировок.
- Таймер отдыха между подходами.
